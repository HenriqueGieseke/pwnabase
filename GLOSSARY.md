# Wireless Security Studies

Terminology for authorized offline password recovery and future correlation with wireless observations.

## Language

**Result sheet**:
A tabular view of JSON files from a selected project data directory. Each file occupies one row, and its nested content is available in a details panel.

**Capture**:
A recorded collection of wireless packets. One capture can contain multiple handshakes or no usable handshake.
_Avoid_: Hash, password

**Handshake**:
A wireless authentication exchange from which password verification material may be extracted.
_Avoid_: Password

**Recovered password**:
A password candidate successfully verified against a captured network authentication record.
_Avoid_: Decrypted hash, cracked hash

**Wordlist exhausted**:
An outcome in which all candidates in a particular wordlist have been tried without recovering a password for the record under examination. It does not establish that recovery is impossible.

**No usable handshake**:
An outcome in which a readable capture yields no authentication material usable by the selected recovery workflow.

**Capture provenance**:
The association of an authentication record or recovery result with its original capture, including the capture's content fingerprint.

**BSSID**:
The address identifying an access-point radio in a wireless observation. It is retained alongside the network name for later correlation.

**SSID**:
The network name advertised or used by a wireless network. Different networks may share the same name.
_Avoid_: Unique network identifier

**Mutation rule**:
A transformation sequence that generates a password candidate from an original seed. Separate rules each start from the original seed.

**Candidate source**:
The origin of the seeds used in a password recovery attempt, such as an external wordlist or the target network's SSID.

**Seed**:
An initial value from which password candidates are generated by applying transformations.

**SSID-derived attempt**:
A recovery attempt whose seeds come only from the network name associated with the authentication record being tested.

**SSID profile**:
A collection of transformation families combined to generate candidates from an SSID, including casing, separators, substitutions and suffixes. A profile describes the combined experiment rather than a single transformation.

**No eligible candidates**:
An outcome in which candidate generation produces no password candidates within the recovery method's supported length range. It does not indicate a tool failure or establish that the password is unrecoverable.

**Rule set**:
An ordered collection of mutation rules used for a recovery attempt. The rule set identifies the transformations tried in addition to the chosen candidate source.

**Batch**:
One execution of the recovery workflow across selected captures and a candidate source.

**Batch configuration**:
The candidate source and transformations that distinguish a group of comparable recovery batches. A change in wordlist contents or transformation behavior creates a different configuration.
